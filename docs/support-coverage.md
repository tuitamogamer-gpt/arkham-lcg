Builder types containing underscores count as declarations. The earlier read-only census of 1,170 assets and 94 investigators missed those types and has been superseded. Card faces, art aliases, scenario references, play modes and executable builders have distinct counts. All 161 published play-mode rows have source declarations; a native `scenarioIds` reference list cannot be used as their gameplay allowlist.

The map preserves 16 Beta and three Alpha play modes. Campaign and multipart tags inherit the published upstream flags; variant rows and authored Barkham metadata are preserved. Passing a focused test does not remove an experimental label.

The installation fields describe the supplied private Linux QA manifest. The separately verified [Mac archive export](macos-runtime-release.md) records its own package, signing, installation and gameplay evidence.

Regenerate source-only coverage from the pinned upstream checkout:

```bash
npm run support:coverage -- --source /path/to/pinned/ArkhamHorror
```

To include retained private QA evidence, supply `--registry /path/to/status-capture.json`, `--native-qa-manifest /path/to/chronicle-native-qa.json` and one `--legal-report /path/to/report.json` for each legal attempt. The manifest verifier checks actual binary, object, test-driver and extension-source identity. Evidence paths outside this repository receive neutral hash identifiers. The public map contains counts and hashes, without saved-game contents or credentials.

A whole-scenario report cannot be promoted from setup, debug assistance, nonzero or missing assistance counters, a different binary, a partial run or a defeat. Epic completion contracts require their own evidence checks; a future successful but unverified contract is kept separate from a confirmed victory. Source declarations and the private aggregate do not certify every upstream interaction.
